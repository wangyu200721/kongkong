# 掌控 · PhoneDeck

用手机控制你的 Windows 电脑：看屏幕、点鼠标、敲键盘、发指令、开应用——扫一次码就连上，之后打开手机就能用。

---

## 这是什么

「掌控」是一套**电脑端 + 手机端**的远控工具，装在自己电脑上，手机通过 Wi-Fi 或虚拟局域网连过来操作这台电脑。

它和其他远控的区别是**为"操作"而不是"演示"设计**：不是投屏看画面，而是让手机变成这台电脑的鼠标键盘，能真的点开软件、输入文字、跑命令。

- 电脑端：一个常驻后台的小程序（`KongKong.exe`），关掉窗口服务照样跑；可以在面板里打开「开机自启」
- 手机端：Android App（内置扫码），也可以直接用浏览器打开，或"添加到主屏幕"当 App 用

## 能干什么

### 屏幕
- 实时画面，自适应清晰度：链路慢就自动降分辨率，恢复后升回来
- 画面没变化时服务端只回一个空响应，**静止时几乎不耗流量**
- 单指/双指上下滑动翻页面，松手有惯性
- 「缩放」按钮手动开启后才接管双指：捏合放大、双指平移；关闭时双指留给滚动
- 轻点 = 左键，长按 = 右键，工具栏还有双击、右键、拖动模式、↑↓ 滚轮

### 键盘
- 16 个高频键一键触发：Win、Alt+Tab、Esc、回车、Ctrl+C/V/A/Z、Win+D、Alt+F4、Tab、F5、←、→、退格、Del
- 退格和 Del 支持长按连发，删一长串字不用点几十下
- 虚拟键盘**边打边发**：不用点「发送」，电脑光标处会同步出现你打的字，删字也是真的退格

### 指令
- 「一句话指令」：说人话就行——`打开微信`、`给张三发微信说 我马上到`、`音量+`、`锁屏`、`搜索 今天的天气`
- 「Shell 终端」：PowerShell 或 cmd，**实时流式输出**，可以随时中断
- 以 `>` 开头的句子直接当命令执行

### 应用
- 常用应用一键启动
- 列出电脑上正在运行的窗口，点一下就切到前台
- 搜索开始菜单里的所有应用（含 UWP）

## 三步用起来

1. **装电脑端**：双击 `KongKong-Setup.exe`，装到 `%LOCALAPPDATA%\Programs\KongKong`，不需要管理员权限
2. **手机扫码**：电脑上打开「掌控」窗口，用手机相机（或内置扫码）扫屏幕上的二维码
3. **开始用**：扫码成功后服务已配对，这台手机会被记住，以后打开即连，**不用再扫**

> 换手机、或者想撤销某台设备的权限，在电脑面板的「已配对设备」里点删除即可。

## 三种连接方式

| 场景 | 怎么连 | 说明 |
|---|---|---|
| 同一个 Wi-Fi | 扫「局域网」二维码 | 最简单，延迟最低 |
| 手机用流量 / 不同网络 | Tailscale 等虚拟局域网 | 两端装 Tailscale 登录同一账号，手机上填电脑的 `100.x.x.x` 地址 |
| 宽带支持公网 IPv6 | 扫「远程」二维码 | 需要路由器放行 8765 端口 |

在面板上可以切换二维码对应哪种地址，也能手填自定义地址。

## 安全设计

- 配对码是 **6 位一次性码**，30 分钟过期，配对成功立刻换一个新的
- 配对接口**按 IP 限速**（5 分钟内失败 8 次就锁），防止被暴力猜码
- 手机端拿到的是设备凭据（`ID.密钥`），服务端**只存 SHA-256 哈希**，看不到原文
- 只能在**本机**打开的管理面板（`127.0.0.1`）才能改设置
- 每个请求都要带设备凭据，没配对的设备一律 401

⚠️ **注意**：电脑端是 HTTP 明文传输。局域网内没关系；如果是跨公网使用，强烈建议走 Tailscale（它自带 WireGuard 加密），不要直接把 8765 端口暴露到公网。

## 系统要求

- 电脑：Windows 10 / 11（64 位）。电脑睡眠后手机就连不上了，面板里有「阻止休眠」开关
- 手机：Android 7.0 及以上；或者任意现代浏览器（iOS 可以用 Safari 打开后"添加到主屏幕"）
- 网络：同一个 Wi-Fi，或都装了 Tailscale

## 安装位置与数据

| 内容 | 位置 |
|---|---|
| 程序本体 | `%LOCALAPPDATA%\Programs\KongKong` |
| 配置 / 配对记录 / 日志 | `%APPDATA%\PhoneDeck` |
| 默认端口 | 8765 |

**覆盖安装不会丢配对**：安装程序只替换程序目录，配置和设备记录都在 `%APPDATA%`，手机不需要重新扫码。

卸载：控制面板「应用」里找「掌控」，或运行安装目录下的 `uninstall.exe`。

## 更新

电脑端面板右上角显示当前版本号（如 `v3.1.1`）：

- 打开面板会自动检查一次，**有新版本会变成高亮的 `v3.1.1 → v3.2.0`**
- 点一下用浏览器打开下载页，下载后覆盖安装即可，配对不丢
- 没有新版本时点一下会提示"已经是最新版"

## 已知限制

- **不能操作以管理员权限运行的程序**（Windows 的 UIPI 限制，所有模拟输入的方案都一样）
- 微信发送是模拟键盘操作：需要电脑上微信已登录，且发送键没有被改成 Ctrl+Enter
- 这是远程控制工具，请只在自己的电脑上用，不要拿它去控制别人的机器
- 没有上架应用商店（国内上架需要软件著作权 + APP 备案）
